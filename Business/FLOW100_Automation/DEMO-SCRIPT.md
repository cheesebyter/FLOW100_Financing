# Bildschirmaufnahme: 60–90 Sekunden

Vorbereitung: Demo einmal starten, danach die beiden Beispieldateien und den HTML-Bericht bereithalten. Nur erfundene Beispieldaten zeigen. Als eigenständige Arbeitsprobe bezeichnen.

**0–15 Sekunden – Das Problem**

Zeige die beiden Quelldateien nebeneinander.

„Diese beiden Kundenlisten stammen aus unterschiedlichen Systemen. Die Spalten und Trennzeichen unterscheiden sich. Ausserdem gibt es Dubletten, fehlende Werte und einen widersprüchlichen Datensatz.“

**15–30 Sekunden – Die Verarbeitung**

Starte `Start-Demo.cmd`.

„Dieses kleine Tool bringt beide Dateien in dieselbe Struktur, entfernt überflüssige Leerzeichen und prüft Pflichtfelder sowie E-Mail-Formate. Die Verarbeitung läuft lokal.“

**30–55 Sekunden – Das Ergebnis**

Zeige die Kennzahlen und die importbereiten Kunden im Browser.

„Von zwölf Eingabezeilen sind sechs Kunden importbereit. Ein identisches Duplikat wird entfernt. Fünf Zeilen benötigen eine Prüfung.“

**55–75 Sekunden – Warum die Prüfung zählt**

Scrolle zu den beiden Konflikthinweisen für K102.

„Bei dieser Kundennummer stehen zwei unterschiedliche E-Mail-Adressen. Das Tool rät nicht: Beide Versionen bleiben aus dem Import ausgeschlossen. Quelldatei und Zeile machen das Problem nachvollziehbar.“

**75–90 Sekunden – Dein Angebot**

„Sie erhalten eine importfertige Datei, einen Prüfbericht und ein wiederverwendbares Tool. Für Ihren Ablauf vereinbaren wir die Quellstruktur, das Zielformat und die Prüfregeln schriftlich.“

## English version

“These two customer exports use different columns and delimiters. They also contain duplicates, missing values and conflicting records.

This small tool standardizes both files, trims surrounding whitespace and checks required fields and email formatting. Everything runs locally.

Twelve input rows produce six import-ready customers. One exact duplicate is removed, and five rows need review.

This customer ID has two different email addresses. Instead of guessing, the tool excludes both versions and identifies their source files and row numbers.

The deliverables are an import-ready file, a review report and a reusable tool. For your workflow, we agree on the input structure, output format and validation rules in writing.”
